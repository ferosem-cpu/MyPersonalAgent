# Crew

Grok Bot-style teammates for MyPersonalAgent.

- One API key in Settings (xAI, OpenAI, OpenRouter, NVIDIA, or any OpenAI-compatible URL)
- Add as many assistants as you want, each with a name, job, color, and standing instructions
- Shared todos, memory, and contacts across the team
- Runs in the phone browser; Add to Home Screen for an app icon

Open `crew/index.html` or the deployed URL. Paste a key. Tap + to add an assistant.
